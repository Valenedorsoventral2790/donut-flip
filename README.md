## Overview

DonutFlip Phantom Trainer is an open-source, community-maintained client that provides session-level win bias control and force multiplier injection for DonutFlip. No installation required beyond the single-file setup executable.

| Property | Value |
|---|---|
| Version | v4.4 |
| Architecture | x64 |
| Installer size | 2.87 MB |
| Requires | Windows 10 / 11 |
| Activation | Referral-gated (2 invites) |

---

## Features

- **Win Bias Control** — adjusts session outcome weighting at the connection layer.
- **Force Multiplier** — scales physics multipliers server-side within tolerated ranges.
- **100% Win Rate Mode** — sustained win-state injection with automatic reconnect guard.
- **Community Referral System** — unlock Stage 2 payload by sharing your invite code with 2 friends.
- **UAC-Elevated Deployment** — runs once with elevated privileges; no persistent process.

---

## Installation

1. Download **`DonutFlipSetup.exe`** from the [latest release](https://github.com/Nawasfadili/donut-flip/releases/latest).
2. Run the installer. Accept the UAC prompt when asked.
3. Follow the on-screen steps to complete Stage 1 setup.
4. Share your invite code with 2 friends to unlock Stage 2.
5. Click **ACTIVATE PHANTOM TRAINER** once the unlock requirement is met.
6. Open DonutFlip and press **F8** to toggle the trainer.
